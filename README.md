## 📘 About This Repository
This repository contains complete documentation and implementations for the **STQA Laboratory course**, covering:

- Manual Testing Techniques  
- White Box & Black Box Testing  
- Unit Testing (JUnit)  
- Automation Testing (Selenium)  
- API Testing (Karate DSL)  
- Performance Testing  
- Software Quality Tools (TQM)

## 🧪 Laboratory Assignments

### 📋 Assignment 1: Manual Black Box Testing
- Designed test cases using:
  - Boundary Value Analysis (BVA)
  - Equivalence Partitioning (EP)
- Validated input fields and functional behavior.

---

### 📐 Assignment 2: White Box Testing & Path Analysis
- Created Control Flow Graph (CFG)
- Calculated Cyclomatic Complexity:

- V(G) = E - V + 2P
- E = edges  
- V = vertices  
- P = connected components  

- Identified independent execution paths.

---

### ☕ Assignment 3: Unit Testing (JUnit 5)
- Implemented automated test cases using JUnit 5
- Used assertions:
  - `assertEquals()`
  - `assertThrows()`

---

### 🐛 Assignment 4: Defect Tracking
- Created structured bug reports including:
  - Defect ID
  - Steps to reproduce
  - Severity & Priority
  - Expected vs Actual result

---

### 🌐 Assignment 5: Selenium WebDriver Automation
- Automated browser testing using Selenium WebDriver
- Used WebDriverManager for driver handling
- Implemented Explicit Waits (`WebDriverWait`)

---

### 🗃️ Assignment 6: Data-Driven Testing
- Implemented framework separating test logic and data
- Executed multiple test cases using datasets

---

### 🛡️ Assignment 7: Parameterization & Exception Handling
- Tested application robustness using invalid inputs
- Verified proper exception handling and responses

---

### ⏱️ Assignment 8: Performance Testing
- Measured system performance under load
- Key metrics:
  - Requests Per Second (RPS)
  - Response Time (ms)
  - Error Rate (%)

---

### 🤖 Assignment 9: API Testing (Karate DSL)
- Implemented BDD-based API testing
- Covered full CRUD lifecycle:
- - Validated response structure using matchers:
  - `#string`
  - `#number`

---

### 📊 Assignment 10: Quality Tools (TQM)
- Applied Total Quality Management principles
- Created:
  - Fishbone (Cause & Effect) Diagram
  - Pareto Chart (80/20 analysis)
